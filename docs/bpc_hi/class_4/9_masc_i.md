# इकारान्त पुल्लिंग संज्ञा शब्द (Masculine Noun ending in -i)

DPD में ऐसी लगभग 400 संज्ञाएँ हैं[^12]।

## इकारान्त पुल्लिंग रूप-विधान (Declension of -i masc) {: #declension-of-i-masc}

| कारक (Case) | एकवचन (Singular) | बहुवचन (Plural) |
| --- | --- | --- |
| 1. प्रथमा (Nominative) | अग्गि (agg**i**) | अग्गी (agg**ī**)<br>अग्गयो (agg**ayo**) |
| 2. द्वितीया (Accusative) | अग्गिं (agg**iṃ**) | अग्गी (agg**ī**)<br>अग्गयो (agg**ayo**) |
| 3. तृतीया (Instrumental) | अग्गिना (agg**inā**) | अग्गीहि (agg**īhi**) |
| 4. चतुर्थी (Dative) | अग्गिनो (agg**ino**)<br>अग्गिस्स (agg**issa**) | अग्गीनं (agg**īnaṃ**) |
| 5. पञ्चमी (Ablative) | अग्गिना (agg**inā**)<br>अग्गिम्हा (agg**imhā**)<br>अग्गिस्मा (agg**ismā**) | अग्गीहि (agg**īhi**) |
| 6. षष्ठी (Genitive) | अग्गिनो (agg**ino**)<br>अग्गिस्स (agg**issa**) | अग्गीनं (agg**īnaṃ**) |
| 7. सप्तमी (Locative) | अग्गिम्हि (agg**imhi**)<br>अग्गिस्मिं (agg**ismiṃ**) | अग्गीसु (agg**īsu**)<br>अग्गिसु (agg**isu**) |
| 8. सम्बोधन (Vocative) | अग्गि (agg**i**) | अग्गी (agg**ī**)<br>अग्गयो (agg**ayo**) |

उदा. समाधि (samādhi), गहपति (gahapati), मुनि (muni), गामणि (gāmaṇi), इसि (isi), सुचि (suci), ञाति (ñāti), पाणि (pāṇi), सारथि (sārathi), अञ्जलि (añjali), उपधि (upadhi), कासि (kāsi)
