# Optative (*sattamī*)

Kaccāyana 416. anumati-parikapp’atthesu sattamī.

“When the meaning is consent or possibility, optative”

Please conjugate the word **gacchati** in the optative active voice.

Let’s look at the optative in the reflexive **voice and passive voice.**

(Theory) How is the reflexive formed? How is the passive formed?

**Optative Attanopada “could tame oneself”**
**(√dam + a \> dama)**

| | | |
| --- | --- | --- |
| | **s** | **pl** |
| 3 paṭhama | dam**etha** | *dameraṃ*[^11] |
| 2 majjhima | dam**etho** | *dameyyāvho* |
| 1 uttama | dam**eyyaṃ** | *dameyyāmhe* / *damemase* |

[^11]: The forms shown in italics here and further in the conjugation tables only exist in grammar books.

**Optative Passive Attanopada “could be led (by oneself)”**
**(√nī + ya \> nīya)**

| | | |
| --- | --- | --- |
| | **s** | **pl** |
| 3 paṭhama | nīy**etha** | *nīyeraṃ* |
| 2 majjhima | nīy**etho** | *nīyeyyāvho* |
| 1 uttama | nīy**eyyaṃ** | *nīyeyyāmhe* / *nīyemase* |

A practical example of the optative attanopada:

sace labh**etha** nipakaṃ sahāyaṃ ([DHP328](https://s.dhamma.gift/kn/dhp/index.html#dhp320))

if one **should find** a wise companion …
