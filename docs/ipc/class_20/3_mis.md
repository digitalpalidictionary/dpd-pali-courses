# Missaka-samāsa or Complex Compounds

(mixed-compounds)

Compounds of all sorts may themselves become part of other compounds.

*[SN46.53](https://s.dhamma.gift/sn/sn46/index.html#sn46.53)*  akālo (hoti) **upekkhāsambojjhaṅgassa** bhāvanāya

upekkhāsambojjhaṅga \< upekkhā + sambojjhaṅga (kammadhāraya)

sambojjhaṅga \< sambodh**iyā** + aṅga (chaṭṭhī tappurisa)

*[MN53](https://s.dhamma.gift/mn/mn53/index.html)* **vijjācaraṇasampanno** so seṭṭho devamānuse'ti

vijjācaraṇasampanna \< vijjācaraṇ**ena** + sampanna (tatiyā tappurisa)

vijjācaraṇa \< vijjā **ca** caraṇa **ca** (dvanda)

*[SN22.1](https://s.dhamma.gift/sn/sn22/index.html#sn22.1)*  sappurisānaṃ dassāvī **sappurisadhammassa** kovido **sappurisadhamme** suvinīto

sappurisadhamma \< sappuris**ānaṃ** + dhamma (chaṭṭhī tappurisa)

sappurisa \< santa (sat) + purisa (kammadhāraya)

*[SN43.1](https://s.dhamma.gift/sn/sn43/index.html#sn43.1)* katamo ca, bhikkhave, **asaṅkhatagāmimaggo**? **kāyagatāsati**

asaṅkhatagāmimagga \< asaṅkhatagāmī + magga (kammadhāraya)

asaṅkhatagāmī \< asaṅkhat**aṃ** + gāmī (dutiyā tappurisa)

kāyagatāsati \< kāyagata + sati (kammadhāraya)

kāyagata \< kāy**aṃ** + gata (dutiyā tappurisa)
