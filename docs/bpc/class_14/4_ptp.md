# Potential Participle (ptp)

This is also called the **Future Passive Participle**.

evaṃ eso pañho **pucchitabbo**. ([DN16](https://s.dhamma.gift/dn/dn16/index.html))

Thus this question **should be asked**.

As you can see from the example, like all the participles, they are **verbal adjectives**; they give more information about the noun they are describing.

Which noun does it describe in the given example?

## Potential Participles Can Mean

to be…

should be…

could be…

must be…

can be…

ought to be…

fit to be…

able to be…

suitable to be…

depending on the context

Potential Participles are easy to recognise. The most common endings are **-tabba**, **-itabba** and **-anīya**, **-aṇīya**, **-aniya**.

| | | | **should be/fit to be** |
| --- | --- | --- | --- |
| √kar | to do | kar**aṇīya** | done |
| √vac | to say | vac**anīya** | said |
| √chaḍḍ | to discard | chaḍḍ**anīya** | discarded |
| vi + ā + √kar | to answer | vyākar**aṇīya** | answered |
| √dā | to give | dā**tabba** | given |
| pa + √hā | to give up | pahā**tabba** | given up |
| √khād | to chew | khād**itabba** | eaten |
| √dis | to see | pass**itabba** | seen |
| √pucch | to ask | pucch**itabba** | asked |
| √sikkh | to train | sikkh**itabba** | trained |
| √vand | to worship | vand**itabba** | worshipped |
| √vid | to know | ved**itabba** | known |

## How to Form the Potential Participle

The most common formation is equivalent to Sanskrit **-tavya**.

### 1. root + -tabba or -itabba

| | | | | **should be/fit to be** |
| --- | --- | --- | --- | --- |
| abhi + √nand | to approve | + itabba | abhinanditabba | approved |
| abhi + √vad | to welcome | + itabba | abhivaditabba | welcomed |
| √ādā | to take | + tabba | ādātabba | taken |
| ā + √har | to bring | + itabba | āharitabba | brought |
| ā + √nī | to fetch | + tabba | ān**e**tabba | fetched |
| √bandh | to bind | + itabba | bandhitabba | bound |
| √dā | to give | + tabba | dātabba | given |
| √es | to seek | + itabba | esitabba | looked for |
| √han | to kill | + tabba | hantabba | killed |

### 2. root + -anīya

| | | | | **should be/fit to be** |
| --- | --- | --- | --- | --- |
| √bandh | to bind | + anīya | bandhanīya | bound, tied |
| √chaḍḍ | to discard | + anīya | chaḍḍanīya | discarded |
| √dis | to see | + anīya | dassanīya | seen |
| √kham | to endure | + anīya | khamanīya | endured |
| √pūj | to worship | + anīya | pūjanīya | worshipped |
| √vac | to say | + anīya | vacanīya | said |
| √vajj | to avoid | + anīya | vajjanīya | avoided |

### 3. √root + -ya or -iya

Because of sandhi, these examples are tricky to spot unless you know them.

They can be used as nt. nouns.

| | | | | **should be/fit to be** |
| --- | --- | --- | --- | --- |
| √bhuj | to eat | + \*ya | bhojja | eaten (food) |
| √has | to laugh | + ya | hassa | laughed at (joke) |
| √gah | to take | + ya | ga**yh**a | taken |
| √kar | to do | + \*iya | kāriya | done |
| √ji | to conquer | + \*ya | jeyya | conquered |
| √lih | to lick | + \*ya | leyya | licked |
| √nī | to lead | + \*ya | neyya | led |
