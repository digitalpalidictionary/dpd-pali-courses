# How to ask a question with Adverbs & Indeclinables

| | |
| --- | --- |
| api | have? did? |
| api nu | (marks a yes/no question) is it? did? would? |
| nu | (adds a question mark) |
| kahaṃ | where? |
| katama | what?; which? |
| kasmā | why? |
| kathaṃ | how? |
| kiṃ | what? which? why? |
| kiñca (kiṃ + ca) | and what? but why? etc |
| kinti | how? in what way? |
| kīva | how far? how much? |
| kuhiṃ | where? |
| kuvaṃ | where? |

**kathaṃ** nu tvaṃ, mārisa, oghaṃ atari? ([SN1.1](https://s.dhamma.gift/sn/sn1/index.html#sn1.1))

But **how**, dear sir, did you cross the flood?
