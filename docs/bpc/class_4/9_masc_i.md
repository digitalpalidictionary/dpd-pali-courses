# Masculine Nouns Ending in -i

There are about 400 of these nouns in the DPD[^12].

## Declension of -i masc

| | Singular | Plural |
| --- | --- | --- |
| 1.nom | agg**i** | agg**ī** / agg**ayo** |
| 2.acc | agg**iṃ** | agg**ī** / agg**ayo** |
| 3.inst | agg**inā** | agg**īhi** |
| 4.dat | agg**ino** / agg**issa** | agg**īnaṃ** |
| 5.abl | agg**inā** / agg**imhā** / agg**ismā** | agg**īhi** |
| 6.gen | agg**ino** / agg**issa** | agg**īnaṃ** |
| 7.loc | agg**imhi** / agg**ismiṃ** | agg**isu** / agg**īsu** |
| 8.voc | agg**i** | agg**ī** / agg**ayo** |

e.g. samādhi, gahapati, muni, gāmaṇi, isi, suci, ñāti, pāṇi, sārathi, añjali, upadhi, kāsi


[^12]: This statistic is relevant for the year 2023.
