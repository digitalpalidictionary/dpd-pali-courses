# Personal Pronouns

The various declensions of *ahaṃ* “I” and *tvaṃ* “you” are extensively used in the Tipiṭaka.

**1st person ahaṃ**

| | **singular “I”** | **plural “We”** |
| --- | --- | --- |
| 1.nom | ahaṃ | mayaṃ / amhe |
| 2.acc | maṃ / mamaṃ / **me** | amhe / amhākaṃ / **no** |
| 3.inst | mayā / **me** | amhehi / **no** |
| 4.dat | mama / mayhaṃ / mamaṃ / **me** | amhaṃ / amhākaṃ / **no** |
| 5.abl | mayā | amhehi |
| 6.gen | mama / mayhaṃ / mamaṃ / **me** | amhaṃ / amhākaṃ / **no** |
| 7.loc | mayi | amhesu |

**2nd person tvaṃ**

| | **singular “you”** | **plural “you all”** |
| --- | --- | --- |
| 1.nom | tvaṃ / tuvaṃ | tumhe |
| 2.acc | taṃ / tuvaṃ / tavaṃ / **te** | tumhe / tumhākaṃ / **vo** |
| 3.inst | tayā / **te** | tumhehi / **vo** |
| 4.dat | tava / tuyhaṃ / **te** | tumhaṃ / tumhākaṃ / **vo** |
| 5.abl | tayā | tumhehi |
| 6.gen | tava / tuyhaṃ / **te** | tumhaṃ / tumhākaṃ / **vo** |
| 7.loc | tayi | tumhesu |
