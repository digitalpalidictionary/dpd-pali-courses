# Class 1

**Why study Pāḷi?**

Please come up with at least 3 reasons why you want to study Pāḷi. Write them down and share with your classmates.

**What is your Pāḷi name?**

If you have one, make sure you know the literal and figurative meaning of your Pāḷi name. If you don't have one, you can create one for yourself. Use [DPD dictionary](https://dpdict.net): English - Pāḷi and Pāḷi - English.

## Course Structure {: #course-structure}

1. Class meeting once per two weeks (2h / class)
    - Short review test
    - Questions related to the exercises
    - New grammar information
    - Practical examples from the Tipiṭaka
2. Homeless work[^1]
    - Grammar Exercises (3-6 h / class)
    - Daily Vocabulary and Grammar Revision (Anki Decks) (20-40 min / day)
        \- Vocab Pāḷi Class
        \- Grammar Pāḷi Class
3. Weekly student meeting (1h / class)
4. How to use digital tools
5. Extra Reading for those who want to broaden and deepen their understanding.
6. Be up-to-date.

[^1]: Meant as a humorous element. The Pāḷi course was offered originally to the Bhikkhu Saṅgha, who ideally go forth from home to homelessness (agārasmā anagāriyaṃ pabbajanti).

## Homeless work

1.  Set up digital tools for yourself (and help your classmates)
2.  Learn the basic Buddhist vocabulary from class 1 using Anki Deck “Vocab Pāḷi Class”
3.  Learn abbreviations from “Grammar Pāḷi Class”

-   Find 2–3 of your favourite and most inspiring sentences from the Pāḷi Tipiṭaka.
