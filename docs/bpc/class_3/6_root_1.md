# Root Group 1 - bhūvādigaṇa

= bhū + ādi + gaṇa

= √bhū + etc + group

67% of roots in Pāḷi (around 500) [^9] belong to the first root group.

[^9]: Statistical numbers are based on DPD root analysis. This data is relevant for the year 2026.

√gam (go) √ṭhā (stand)

√dis (see) √dhā (place, support)

√kam (go) √i (come, go)

√bhū (be) √car (act, go)

This group has the conjugational sign **a**. All these verbs get formed like this:

**root + conjugational sign \> base**

**[prefix(es)] + base + verbal ending \> verb**

√kam (go) + **a** \> kama

kama + ti \> kamati (he goes)

√dhāv (run) + **a** \> dhāva

pari + dhāva + ti \> paridhāvati (he runs around)

√car (walk) + **a** \> cara

pari + cara + ti \> paricarati (he walks around)
